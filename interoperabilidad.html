PROTECCIÓN DE LA INFORMACIÓN

Seguridad de los datos

Urabá Crea incorpora medidas para proteger la información durante el registro, la consulta y el intercambio de datos.

Contraseñas protegidas

El backend utiliza password_hash() para guardar contraseñas como hashes y password_verify() para validarlas. No se guardan en texto plano.

Consultas preparadas

Las operaciones SQL utilizan consultas preparadas PDO para reducir el riesgo de inyección SQL.

Validación de datos

La API valida campos obligatorios, formatos, tipos y longitudes antes de procesar una solicitud.

Intercambio controlado

El simulador exige POST y JSON, limita el tamaño de la solicitud y devuelve errores generales sin exponer detalles internos.

Privacidad en la demostración

Los datos de prueba no se almacenan ni se envían a una transportadora real.

Cabeceras de seguridad

El servicio añade cabeceras para evitar la interpretación de contenido como scripts, restringir el uso en marcos y evitar caché de respuestas.

Para producción: publicar el sitio con HTTPS, usar credenciales de base de datos únicas y privadas, restringir permisos, mantener copias de seguridad y no subir config/database.php ni contraseñas a GitHub. La demostración local no sustituye una auditoría de seguridad.
Nota académica: esta demostración utiliza un endpoint PHP local que representa al sistema externo de logística. Se intercambian datos reales de prueba mediante HTTP POST y JSON; no existe conexión con una transportadora real.
